# Story 2.3: 시뮬레이션 결과 화면 표시

Status: done

## Story

As a 관리자,
I want 시뮬레이션 실행 후 예상 수익 수치와 종합 판정을 화면에서 확인하고 싶다,
So that 해당 부동산의 수익성을 즉시 파악하고 제안서 출력으로 이어갈 수 있다.

## Acceptance Criteria

1. **Given** 시뮬레이션 API 응답 수신 **When** 결과 화면 렌더링 **Then** SimulationResultCard에 예상 월매출, 점유율, 순수익이 수치로 표시되고 카드가 슬라이드인 애니메이션으로 등장함

2. **Given** verdict가 "추천" **When** VerdictBadge 렌더링 **Then** 초록색(#16A34A) 배지에 "✅ 추천 — 상위 N%" 텍스트 표시됨

3. **Given** fallback_used가 true **When** 결과 화면 렌더링 **Then** amber 경고 배너 "유사 지점 데이터 부족 — 전체 평균으로 대체합니다"가 비침습적으로 표시됨

4. **Given** 결과 표시 완료 **When** 하단 버튼 영역 렌더링 **Then** "제안서 출력" Primary 버튼이 활성 상태로 표시됨

## Dev Notes

### 컴포넌트 구조

```
simulation/page.tsx (Server Component)
  └── SimulationContainer ("use client") [전체 레이아웃 + 상태]
        ├── 좌측 패널 → SimulationForm (onResult 콜백 전달)
        └── 우측 패널
              ├── result=null → placeholder
              └── result≠null → SimulationResultCard
                    ├── FallbackBanner (fallback_used=true 시)
                    ├── 3개 수치 카드 (월매출/점유율/순수익)
                    ├── VerdictBadge
                    └── "제안서 출력" 버튼
```

### 슬라이드인 애니메이션 패턴

```tsx
const [visible, setVisible] = useState(false);
useEffect(() => { setVisible(true); }, []);

<div className={`transform transition-all duration-300 ${
  visible ? "translate-x-0 opacity-100" : "translate-x-5 opacity-0"
}`}>
```

매번 새 result가 들어올 때 재애니메이션: `key={result.estimated_monthly_revenue}`.

### 수치 포맷

- 월매출/순수익: `Math.round(value / 10000).toLocaleString("ko-KR")` → "만원" 단위
- 점유율: `value.toFixed(1)` → "%"
- percentile "상위 N%": `Math.round(100 - result.percentile)` (최소 1)
