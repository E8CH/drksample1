## Dev Notes

### 아키텍처 결정: NavBar 컴포넌트 분리

`app/dashboard/layout.tsx`는 서버 컴포넌트여야 하므로, `usePathname()` 클라이언트 훅을 사용하는 네비게이션을 별도 `"use client"` 컴포넌트(`NavBar.tsx`)로 분리. layout.tsx는 NavBar를 import하여 렌더링.

```tsx
// nextjs-frontend/components/layout/NavBar.tsx
"use client";
import { usePathname } from "next/navigation";
import Link from "next/link";
import { logout } from "@/components/actions/logout-action";

const NAV_LINKS = [
  { href: "/dashboard/simulation", label: "입지분석" },
  { href: "/dashboard/board", label: "게시판" },
];

export default function NavBar() {
  const pathname = usePathname();
  return (
    <nav className="fixed top-0 left-0 right-0 h-14 flex items-center justify-between px-6 bg-white border-b border-dalock-border z-50">
      <span className="text-dalock-primary font-semibold text-xl">다락</span>
      <div className="flex items-center gap-2">
        {NAV_LINKS.map((link) => (
          <Link
            key={link.href}
            href={link.href}
            className={
              pathname === link.href || pathname.startsWith(link.href + "/")
                ? "bg-dalock-primary text-white rounded-md px-3 py-1.5 text-sm font-medium"
                : "text-dalock-text2 hover:text-dalock-text1 rounded-md px-3 py-1.5 text-sm"
            }
          >
            {link.label}
          </Link>
        ))}
        <form action={logout}>
          <button
            type="submit"
            className="ml-4 text-sm text-dalock-text2 hover:text-dalock-text1 border border-dalock-border rounded-md px-3 py-1.5"
          >
            로그아웃
          </button>
        </form>
      </div>
    </nav>
  );
}
```

### F9 defer 해결

기존 `dashboard/layout.tsx`의 `onClick={logout}` Server Action 호출 패턴을 `<form action={logout}>` 패턴으로 교체. Next.js App Router에서 Server Action을 클라이언트 이벤트 핸들러로 직접 전달하는 것은 가능하나, form action 패턴이 더 명시적이고 JS 비활성화 환경에서도 동작함.

### 주의사항

- `tailwind.config.js`에서 기존 shadcn CSS variable 기반 colors 블록(`background`, `foreground`, `primary` 등)은 건드리지 말 것 — shadcn 컴포넌트가 이에 의존함
- `dalock` 네임스페이스로 완전히 분리하여 충돌 방지
- NavBar는 `fixed`이므로 `<main className="pt-14">` 필수 — 없으면 콘텐츠가 NavBar 뒤로 숨음
- `app/layout.tsx` body에 `font-sans` 클래스가 없으면 Pretendard가 적용되지 않음
