I want 전체 지점의 10년치 수익 실적을 테이블에서 조회하고 정렬·필터하고 싶다,

## Acceptance Criteria

**AC1 — 테이블 기본 렌더링**
Given `/dashboard/board` 접근
When BranchDataTable 렌더링
Then 지점명, 주소, 기준연월, 월매출, 전기세, 운영비, 순수익, 점유율 컬럼이 표시되고
     기준연월 내림차순으로 기본 정렬됨. 페이지당 50건.

**AC2 — 컬럼 정렬**
Given 컬럼 헤더 클릭 (정렬 가능 컬럼: 지점명, 기준연월, 월매출, 순수익, 점유율)
When 정렬 토글
Then 오름/내림차순이 전환되고 URL 쿼리 파라미터(`?sort_by=sale_date&order=desc`)에 반영됨
     (기존 필터·페이지 파라미터는 유지)

**AC3 — 연도 필터**
Given 연도 필터 셀렉트에서 "2025" 선택
When 필터 적용
Then 2025년 데이터만 표시됨. URL에 `?year=2025` 파라미터 반영.
     연도 변경 시 page는 1로 초기화됨.

**AC4 — 지점명 검색**
Given 지점명 검색창에 "강남" 입력 후 Enter 또는 검색 버튼 클릭

Then "강남"이 포함된 지점명의 행만 표시됨. URL에 `?branch_name=강남` 반영.
     검색 시 page는 1로 초기화됨.

**AC5 — 서버사이드 페이지네이션**
Given 페이지네이션 버튼 클릭
When 페이지 이동
Then 서버사이드에서 해당 페이지 데이터만 조회됨 (전체 클라이언트 로드 없음).
     URL에 `?page=2` 반영. 총 건수와 현재 페이지/전체 페이지 표시됨.

**AC6 — 빈 상태**
Given 데이터가 없거나 검색 결과 없을 때
When BranchDataTable 렌더링
Then "데이터가 없습니다" 빈 상태 메시지 표시 (빈 행 없음, 최소 높이 유지)

**AC7 — 로딩 상태**
Given 페이지 접근 또는 필터/정렬 변경 시
When 서버에서 데이터 fetching 중
Then 스켈레톤 UI (행 형태 유지) 또는 로딩 인디케이터 표시

**AC8 — 인증 보호**

**SQL 쿼리 설계 (SQLAlchemy text() 사용):**

월별 집계 쿼리 구조:
```sql
WITH monthly_stats AS (
    SELECT
        s.branch_name,
        DATE_TRUNC('month', s.sale_date) AS sale_month,
        SUM(s.daily_revenue)             AS monthly_revenue
    FROM sales s
    WHERE (:year IS NULL OR EXTRACT(YEAR FROM s.sale_date) = :year)
      AND (:branch_name IS NULL OR s.branch_name ILIKE :branch_name_pattern)
    GROUP BY s.branch_name, DATE_TRUNC('month', s.sale_date)
),
avg_revenue AS (
    SELECT sale_month, AVG(monthly_revenue) AS avg_rev
    FROM monthly_stats
    GROUP BY sale_month
)
SELECT
    ms.branch_name,
    b.address,
    ms.sale_month,
    ms.monthly_revenue,
    COALESCE(o.electricity_fee, 0)  AS electricity_fee,
    COALESCE(o.operating_cost, 0)   AS operating_cost,
    ms.monthly_revenue
        - COALESCE(o.electricity_fee, 0)
        - COALESCE(o.operating_cost, 0) AS net_profit,
    ROUND(
        ms.monthly_revenue / NULLIF(ar.avg_rev, 0) * 100,
        1
    )                                AS occupancy_rate
FROM monthly_stats ms
JOIN branches b  ON b.branch_name = ms.branch_name
JOIN avg_revenue ar ON ar.sale_month = ms.sale_month
LEFT JOIN operations o
    ON o.branch_name = ms.branch_name
   AND o.month       = ms.sale_month
ORDER BY {sort_col} {order_dir}
LIMIT :limit OFFSET :offset
```

- `:branch_name_pattern` = `f"%{branch_name}%"` (ILIKE 와일드카드)
- `sort_col` 허용 목록: `ms.branch_name`, `ms.sale_month`, `ms.monthly_revenue`, `(ms.monthly_revenue - ...) net_profit`, `occupancy_rate`
- 총 건수는 동일 조건으로 `COUNT(*)`하는 별도 쿼리 실행

### 프론트엔드: 서버사이드 페치 (board/page.tsx)

board/page.tsx는 **Server Component**로 구현. `searchParams`로 필터/정렬/페이지를 읽고
FastAPI에서 데이터를 서버사이드 fetch한 후 BranchDataTable에 props로 전달.

```typescript
// app/dashboard/board/page.tsx
import { cookies } from "next/headers";
import BranchDataTable from "@/components/board/BranchDataTable";
import TableToolbar from "@/components/board/TableToolbar";
import { SalesListResponse } from "@/lib/definitions";

type SearchParams = {
  sort_by?: string;
  order?: string;
  page?: string;
  year?: string;
  branch_name?: string;
};

async function fetchSales(params: SearchParams): Promise<SalesListResponse> {
  const cookieStore = await cookies();
  const token = cookieStore.get("access_token")?.value;
  const url = new URL(`${process.env.API_URL}/sales`);
  // append params...
  const res = await fetch(url.toString(), {
    headers: { Cookie: `access_token=${token}` },
    cache: "no-store",
  });
  if (!res.ok) throw new Error("Failed to fetch sales");
  return res.json();
}

export default async function BoardPage({ searchParams }: { searchParams: SearchParams }) {
  const params = await searchParams;
  const data = await fetchSales(params);
  return (
    <div className="p-6 flex flex-col gap-4">
      <TableToolbar initialYear={params.year} initialBranchName={params.branch_name} />
      <BranchDataTable
        data={data.data}
        total={data.total}
        page={data.page}
        limit={data.limit}
        sortBy={params.sort_by ?? "sale_date"}
        order={(params.order as "asc" | "desc") ?? "desc"}
      />
    </div>
  );
}
```

**주의:** Next.js 15에서 `searchParams`는 Promise → `await searchParams` 필요.
