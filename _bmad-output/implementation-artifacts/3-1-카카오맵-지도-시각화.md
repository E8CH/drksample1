# Story 3.1: 카카오맵 지도 시각화

Status: ready-for-dev

## Story

As a 관리자,
I want 시뮬레이션 결과 화면에서 분석 대상 위치와 인근 기존 지점들을 지도에서 확인하고 싶다,
So that 입지의 상권 맥락을 직관적으로 파악할 수 있다.

## Acceptance Criteria

1. **Given** 시뮬레이션 실행 후 결과 수신 **When** KakaoMapView 렌더링 **Then** 지도에 분석 대상 위치(★ 파란 핀)가 표시되고 0.3s 페이드인 애니메이션으로 등장함

2. **Given** 인근 가상 지점 데이터 수신 **When** 지도 핀 렌더링 **Then** 인근 가상 지점들이 ● 회색 핀으로 표시됨 (데이터 없으면 핀 없이 지도만 표시됨)

3. **Given** 주소 입력 완료 후 시뮬레이션 실행 **When** 지오코딩 API 호출 **Then** 서버사이드(FastAPI KakaoMapProvider)에서 주소→좌표 변환됨. `KAKAO_REST_API_KEY`가 클라이언트에 노출되지 않음.

4. **Given** 지도 영역 렌더링 **When** 스크린리더 접근 **Then** 지도에 `aria-label="카카오맵 — 분석 위치 및 인근 지점 표시"` 속성이 적용됨

5. **Given** Kakao 지오코딩 API 호출 실패(네트워크 오류 또는 주소 미인식) **When** 지오코딩 시도 **Then** 지도 없이 "주소: {address}" 텍스트만 표시하는 fallback UI가 렌더링됨

- MapProvider가 서버사이드 geocoding 수행 → `Coordinates` 반환
- 프론트엔드는 받은 `Coordinates`로 Leaflet 지도 렌더링 (OSM 타일, 무료/무키)
- "KakaoMapView"는 컴포넌트 이름만 유지 (Provider 추상화 의도 준수)
- 향후 `NEXT_PUBLIC_KAKAO_JS_API_KEY` 별도 프로비저닝 시 Kakao JS SDK로 교체 가능

### get_nearby_branches 구현 방식 수정

`KakaoMapProvider.get_nearby_branches(self, coords, radius_km)` → 순수 지리 계산만.

실제로는 DB 쿼리가 필요하므로, 라우터에서 직접 처리:
```python
# routes/map.py
@router.get("/branches/nearby")
async def get_nearby(
    address: str,
    radius_km: float = 2.0,
    _: str = Depends(require_admin),
    db: AsyncSession = Depends(get_async_session),
):
    try:
        target = await map_service.geocode(address)
    except (ValueError, httpx.HTTPError):
        raise HTTPException(422, detail={"detail": "주소 변환 실패", "address": address})
    
    # branches에서 lat/lon IS NOT NULL 조회
    stmt = select(Branch).where(
        Branch.latitude.isnot(None),
        Branch.longitude.isnot(None),
    )
    rows = (await db.execute(stmt)).scalars().all()
    
    pins = [
        BranchPin(
            branch_name=b.branch_name,
            address=b.address,
            latitude=float(b.latitude),
            longitude=float(b.longitude),
        )
        for b in rows
        if _haversine_km(target.latitude, target.longitude, float(b.latitude), float(b.longitude)) <= radius_km
    ]
    return {"target": target, "pins": pins}
```

KakaoMapProvider의 `get_nearby_branches`는 stub 유지 (`return []`) — 라우터에서 DB 직접 조회가 더 명확.

### haversine 함수

```python
import math

def _haversine_km(lat1: float, lon1: float, lat2: float, lon2: float) -> float:
    R = 6371.0
    dlat = math.radians(lat2 - lat1)
    dlon = math.radians(lon2 - lon1)
    a = math.sin(dlat / 2) ** 2 + math.cos(math.radians(lat1)) * math.cos(math.radians(lat2)) * math.sin(dlon / 2) ** 2
    return R * 2 * math.asin(math.sqrt(a))
```
