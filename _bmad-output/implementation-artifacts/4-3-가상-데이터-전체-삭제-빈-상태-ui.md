# Story 4-3: 가상 데이터 전체 삭제 & 빈 상태 UI

## Status: done

## Story

As a 관리자,
I want "전체 삭제" 버튼으로 가상 데이터를 완전히 초기화하고 싶다,
So that 시연 전 데이터를 빈 상태로 만들고 필요 시 재생성할 수 있다.

## Acceptance Criteria

**AC1 — 삭제 확인 다이얼로그**
Given "전체 삭제" 버튼 클릭
When 확인 다이얼로그 표시
Then "이 작업은 되돌릴 수 없습니다. 정말 삭제하시겠습니까?" 메시지와 확인/취소 버튼 표시. ESC 키 및 배경 클릭으로 닫기 불가.

**AC2 — 삭제 실행 & Toast**
Given 다이얼로그에서 "확인" 클릭
When `DELETE /data/all` 호출
Then sales, operations, members 데이터 전체 삭제. 완료 시 Toast "전체 데이터가 삭제되었습니다" 우측 하단 3초 표시.

**AC3 — 빈 상태 UI**
Given 삭제 후 게시판 재렌더링 (또는 원래 데이터 없음)
When BranchDataTable에 데이터 없고 활성 필터 없음
Then "데이터가 없습니다. 전체 재생성 버튼을 눌러주세요." 메시지 + "전체 재생성" CTA 버튼 표시.

**AC4 — 멱등성**
Given 이미 빈 상태에서 `DELETE /data/all` 재호출
When 삭제할 데이터 없음
Then 오류 없이 200 성공 응답 (DELETE는 빈 테이블에서도 정상 완료)

### 백엔드: `fastapi_backend/app/services/data_generator.py` 수정

기존 파일 **끝**에만 추가 (기존 코드 일절 수정 금지):

```python
async def delete_all_data() -> None:
    """sales, operations, members 전체 삭제 (branches 보존, 멱등성 보장)"""
    db_url = settings.DATABASE_URL.replace("postgresql+asyncpg://", "postgresql://")
    conn = None
    try:
        conn = await asyncpg.connect(db_url)
        async with conn.transaction():
            await conn.execute("DELETE FROM sales")
            await conn.execute("DELETE FROM operations")
            await conn.execute("DELETE FROM members")
    finally:
        if conn:
            await conn.close()
```

**핵심 주의:**
- branches 삭제 안 함 (AC2 스펙: sales + operations + members만)
- FK 순서: sales → operations → members (branches 참조 역순)
- `conn = None` + `if conn:` 패턴 — Story 4-2 CR 패치 P1과 동일
- `async with conn.transaction()` — Story 4-2 CR 패치 P2와 동일
- 빈 테이블 DELETE는 PostgreSQL에서 에러 없이 0 rows affected로 성공 → AC4 자동 충족

### 프론트엔드: `nextjs-frontend/actions/data.ts` 수정

기존 파일 **끝**에 추가 (기존 generateData, checkGenerationStatus 수정 금지):

```typescript
export async function deleteAllData(): Promise<{ success: boolean; error?: string }> {
  const cookieStore = await cookies();
  const token = cookieStore.get("access_token")?.value;
  if (!token) return { success: false, error: "unauthorized" };

  const res = await fetch(`${process.env.API_URL}/data/all`, {
    method: "DELETE",
    headers: { Cookie: `access_token=${token}` },
    cache: "no-store",
  });

  if (res.status === 401) return { success: false, error: "unauthorized" };
  if (!res.ok) return { success: false, error: "failed" };
  return { success: true };
}
```
